# Model Card

## Model Details
- **Model name:** `bike_share_regressor`
- **Task:** Regression (predict hourly bike rental count)
- **Primary framework:** scikit-learn
- **Tracking/registry:** MLflow

## Intended Use
- Educational MLOps final project use.
- Supports batch/online inference through FastAPI endpoints.

## Training Data
- Source: UCI Bike Sharing (hourly records).
- Preprocessing and split pipeline are defined in DVC stages.

## Evaluation
- Core metrics: RMSE, MAE, R2.
- Additional subgroup analysis available in `docs/subgroup_metrics.json`.

## Limitations
- Trained on a specific historical period; performance may degrade under drift.
- Monitoring and drift alerts are required before promotion decisions.

## Monitoring
- Serving metrics exposed to Prometheus, including `bike_inference_total` with an `output_class` label (binned predicted demand for this regression task; aligns with “inference count by class” in the rubric).
- Drift checks generated by Evidently reports under `monitoring/evidently_reports/`.
